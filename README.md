# SETH 1 AI PRO

這是一個獨立網站，不需要放進原本的業務網站。

GitHub Pages 建議：
1. 在 GitHub 建立新的 Public repository，例如：seth-ai
2. 建立後把 repository 網址傳回 ChatGPT
3. ChatGPT 會把這個資料夾內容放入新 Repo
4. 再開啟 GitHub Pages，之後即可用 iPhone Safari 開啟並加入主畫面

包含：
- index.html
- manifest.webmanifest
- sw.js
- iPhone / PWA icons

注意：統計值是依輸入樣本計算，不是破解或預知 RNG。
